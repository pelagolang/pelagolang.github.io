---
title: Bundled zone data
description: "std.tzdata: the IANA time zone database bundled with the library, for systems that have none."
---

```text
import std.tzdata
```

`std.tzdata` holds the IANA time zone database (release 2026e) inside the library: 496 names, 446 distinct zones, about 160 KB of data. It is generated by a script and not edited by hand.

You rarely import it. [std.zone](./zone.md) reads it for you:

- `zone.named(name)` uses the system's zone files first (`$TZDIR`, `/usr/share/zoneinfo`) and falls back to this copy when the system has no file of that name. That is what makes zones work on Windows, which has no such directory.
- `zone.bundled(name)` always uses this copy, so the same program gives the same answer on every machine, whatever version of the database the system has.

The module has two functions, `index()` and `data()`, which give the zone names with where each zone's data starts, and the data itself. They exist for `std.zone` and are not meant to be called directly.
