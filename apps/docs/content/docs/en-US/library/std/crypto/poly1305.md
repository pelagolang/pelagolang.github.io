---
title: std.poly1305
description: The Poly1305 one-time message authentication code.
---

```text
import std.hash
import std.poly1305
```

Poly1305 (RFC 8439) is a fast MAC whose 32-byte key must be used for **one message only**. It is normally taken from a ChaCha20 block, which is what [std.aead](../ciphers/aead.md) does, so use that for messages. Use Poly1305 directly only when a protocol asks for it.

| Call | What it does |
| --- | --- |
| `poly1305.sign(key, msg)` | The 16-byte tag. |
| `poly1305.verify(key, msg, tag)` | Compares in constant time. |
| `poly.new(key)`, `update!`, `finish` | The streaming form, for a message in pieces. |

```pelago
import std.hash
import std.poly1305

fn main() {
    const key = hash.fromHex("0101010101010101010101010101010101010101010101010101010101010101") ?? []
    const msg = "hello".bytes().toList()
    const tag = poly1305.sign(key, msg)
    print(hash.hex(tag))
    print(poly1305.verify(key, msg, tag), poly1305.verify(key, "hellp".bytes().toList(), tag))
}
```
